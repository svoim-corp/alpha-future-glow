# Макеты кредитного кабинета

Открыть `index.html` — галерея дизайнов. Макет 01 — `shell.html`; макет 02, главная с базовыми плитками — `home.html`. Описание виджетов — `HOME.md`.

Это HTML/CSS-макеты для обсуждения перед переносом в React. Общая палитра и компоненты подключаются из `../ui-kit/`. Не требуют сборки, внешних шрифтов и интернета.

## Актуальность и перенос в приложение

Срез от 21.10.2026: React-приложение уже существует, дизайн перенесён частично. [Контекст проекта](../PROJECT_CONTEXT.md) описывает готовые части и оставшиеся задачи; [frontend/AGENTS.md](../../AGENTS.md) — правила переноса, [UI-kit](../ui-kit/README.md) — компоненты и токены.

Поведение и данные определяет [актуальная спецификация](../../../docs/API_SPEC.md), для планера — [дополнение](../../../docs/API_SPEC_ADDITIONAL.md). Макеты содержат старые допущения. В частности, загрузка выписки больше не является требованием продукта. Документы к подписанию формирует банк. Поиск, язык, настройки и галерейная навигация в макете не подтверждают наличие этих функций в приложении.

Мастера заявки, подписания и кабинета банка среди этих HTML-макетов нет; их поведение нужно брать из API, а визуальное оформление — из UI-kit и общей оболочки.

## Макет 01: общий каркас

- Навигационная панель слева: Главная, Планер, Мои заявки, Мои кредиты, Каталог, Поддержка. Настройки и Выйти закреплены в нижней группе при достаточной высоте; на коротком экране панель прокручивается.
- Верхняя панель: поиск, переключение темы, язык, профиль. Поиск занимает свободное пространство, остальные элементы сгруппированы справа.
- В рабочей области показана нейтральная композиция-заглушка. Дизайн содержимого страниц ещё не утверждён.
- Под рабочей областью — навигация для просмотра дизайнов: Все макеты, текущий макет и UI kit. Она не является частью будущего продукта.
- Галерея показывает только реально готовый дизайн как ссылку; будущие страницы отмечены как не спроектированные.

## Демонстрационные взаимодействия

Наведение и клавиатурный фокус показывают состояние элементов; активный раздел выделяется цветом и маркером. Готовые страницы связаны HTML-ссылками; оставшиеся демонстрационные разделы каркаса меняют hash, заголовок и активное выделение, показывая заглушку.

Тема использует общие токены, сохраняется локально при доступности localStorage и учитывает настройку ОС до ручного выбора. Язык и профиль раскрывают примеры меню; переключения языка и редактирования профиля нет. Поиск показывает только пример подсказки, не ищет данные. `/` ставит фокус в поиск, Escape закрывает раскрытые элементы. «Выйти» показывает уведомление, сессия не меняется.

До 760 px левая панель открывается кнопкой меню; сохраняются поиск, тема, язык и аватар. Меню закрывается Escape, кнопкой и нажатием вне панели. При открытом меню Tab остаётся внутри него. Все данные компании и профиля синтетические.

## Файлы

- `index.html` — галерея макетов.
- `shell.html` — каркас и SVG-символы иконок, встроенные для работы при открытии файла напрямую.
- `designs.css` — стили каркаса, адаптивность и оформление галереи.
- `shell.js` — только взаимодействия просмотра дизайна.

Локальный просмотр из корня репозитория:

```bash
python3 -m http.server 8766 --bind 127.0.0.1 --directory frontend/docs
```

Галерея — [http://127.0.0.1:8766/designs/](http://127.0.0.1:8766/designs/), витрина — [http://127.0.0.1:8766/ui-kit/](http://127.0.0.1:8766/ui-kit/). Можно открыть `index.html` напрямую.

## Проверка

Историческая проверка HTML-макетов при их создании: в локальном Chrome проверены левая панель и все девять пунктов, переход активного состояния и заголовка, раскрытие профиля и языка, закрытие Escape, пример поиска, переключение темы и мобильное меню. На ширинах 375, 768, 1024, 1440 и 1920 px переполнения страницы нет. Светлая и тёмная версии, мобильное меню и галерея просмотрены визуально. Ошибок JavaScript не обнаружено. Это не проверка текущего React-приложения.

Обновление: навигация перенесена влево. В тёмном каркасе усилены рубиновые акценты активного пункта, логотипа и фоновых подсветок. У поиска убраны квадратная рамка фокуса и значок `/`; фокус обозначается мягкой заливкой всей области поиска.
