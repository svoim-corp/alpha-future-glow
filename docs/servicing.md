# Servicing — кредиты и платежи

Зона Servicing (`backend/internal/servicing`, разработчик A): выданные кредиты, график платежей, платёжный календарь,
напоминания о платежах. Схема БД — `servicing`. ТЗ заканчивает путь выдачей, обслуживание — допущение команды.

## Кредит и график

Реализовано. Кредит заводится при выдаче (`POST /applications/{id}/contract/disburse`, зона Offer) через
`shared.Loans.Open`, один на заявку: повторная выдача возвращает уже заведённый кредит (`l-<номер>`).

- Условия — из подписанного договора: сумма, срок, ставка, отсрочка, номер договора `КД-…`. Название продукта
  сохраняется в кредите.
- График аннуитетный. Проценты месяца — на остаток долга по ставке / 12, округление до рубля. В отсрочку — только
  проценты. Затем равные платежи (`monthlyPayment` = аннуитет на `срок − отсрочка` месяцев); последний платёж гасит
  остаток, поэтому сумма основного долга равна сумме кредита до рубля.
- Дата n-го платежа — то же число, что и дата выдачи, через n месяцев; в коротком месяце — последний день
  (31 января → 28 февраля).
- Платежей в демо не бывает: строки графика `PLANNED`.

## API

Все эндпоинты — для клиента: он видит кредиты своей компании; сотрудник банка — `403`, чужой кредит — `404`.
Даты — `YYYY-MM-DD`. Статус платежа в ответах: `PLANNED`, `PAID` или `OVERDUE` — неоплаченный платёж с прошедшей
датой (вычисляется при чтении, «сегодня» — по UTC).

### `GET /loans/summary`

Реализовано. Для главной: число действующих кредитов и ближайший платёж — дата ближайшего неоплаченного платежа
(сегодня или позже) и сумма всех платежей компании в эту дату. Платежей впереди нет — `nextPayment: null`.

```json
{ "activeLoans": 1, "nextPayment": { "date": "2026-11-20", "amount": 61958 } }
```

### `GET /loans`

Реализовано. Выданные кредиты компании, новые первыми.

```json
[
  {
    "id": "l-55",
    "product": { "code": "WORKING", "name": "Оборотный кредит" },
    "amount": 1200000,
    "balance": 1200000,
    "rate": 21.5,
    "term": 24,
    "issuedAt": "2026-10-20",
    "nextPayment": { "date": "2026-11-20", "amount": 61958 },
    "status": "ACTIVE"
  }
]
```

- `balance` — сумма кредита минус оплаченный основной долг.
- `nextPayment` — первый неоплаченный платёж сегодня или позже; просроченные видны в графике (`GET /loans/{id}`).
  Платежей впереди нет — `null`.
