# Offer & Contract — предложение, подписание, выдача

Зона Offer (`backend/internal/offer`, разработчик A): предложение банка по решению, принятие или отказ клиента,
договор и его печатные формы, имитация подписи и выдачи. Схема БД — `offer`.

## Предложение по решению

Реализовано. Решение принимает Scoring (авто) или сотрудник через Underwriting; Scoring публикует `DecisionMade`.
Offer по событию читает решение (`shared.Decisions.LatestDecision`) и заявку и сохраняет предложение. Повторное
событие или новое решение по той же заявке перезаписывает предложение. Уведомление клиенту о решении отправляет
Underwriting, Offer его не дублирует.

- Условия — из решения: продукт, сумма, срок, ставка. Запрошенные — из заявки.
- Ежемесячный платёж — аннуитет по ставке решения; если клиент выбрал отсрочку, долг гасится за `срок − отсрочка`
  месяцев.
- Срок действия предложения — 7 дней с даты решения (`validUntil`, дата в UTC).
- Пояснение для клиента (`explanation` / `reason`). Сотрудник пишет причину для клиента, она показывается как есть.
  Причина авторешения техническая (в ней балл скоринга), поэтому клиенту вместо неё показывается: при отказе —
  «Заявка не прошла автоматическую оценку кредитоспособности», при иных условиях — «Условия подобраны по результатам
  оценки кредитоспособности», при одобрении — без пояснения (`null`).
