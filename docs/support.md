# Support — поддержка

Зона Support (`backend/internal/support`, разработчик A): частые вопросы и обращения клиента. Схема БД — `support`,
вопросы — seed-миграция `0002_seed.sql`.

Ответы на обращения пока никто не пишет: кто отвечает (сотрудник банка или только частые вопросы) — открытый вопрос
в `backend/TASKS.md`. Поэтому обращение остаётся в статусе `OPEN`, `reply` — `null`, уведомление `TICKET_REPLY`
не отправляется.

## API

### `GET /support/faq?step=APPLICATION`

Реализовано. Открыто без входа. Частые вопросы по шагу пути клиента: `PRODUCT`, `APPLICATION`, `DOCUMENTS`,
`STATUS`, `DECISION`. Без `step` — по всем шагам. Неизвестный шаг — `400 VALIDATION_ERROR`.

```json
[
  { "id": "f-4", "step": "APPLICATION", "question": "Нужно ли загружать документы или выписки?", "answer": "Нет. Данные о компании, руководителе, учредителях и оборотах банк берёт из ваших счетов и государственных реестров." }
]
```

Шаг `DOCUMENTS` — про документы к подписанию, которые банк формирует сам: загрузки документов в кабинете нет.

### `POST /support/tickets`

Реализовано. Новое обращение клиента (пользователь с компанией; сотрудник банка — `403`). Со страницы заявки фронт
передаёт `applicationId`; это может быть только заявка своей компании, иначе — `400 VALIDATION_ERROR` по полю
`applicationId` (о чужой заявке через поддержку ничего не узнать).

Запрос:
```json
{ "subject": "Устаревший фактический адрес", "text": "В заявке старый адрес склада, мы переехали", "applicationId": "a-1031" }
```
Ответ `201`:
```json
{ "id": "t-12", "status": "OPEN", "createdAt": "2026-10-20T11:00:00Z" }
```

`subject` — до 200 символов, `text` — до 4000. `POST /admin/seed/reset` удаляет обращения, частые вопросы остаются.

### `GET /support/tickets`

Реализовано. Обращения текущего пользователя (последние 100), недавно изменённые первыми. Обращения коллег из той же
компании не показываются: это переписка конкретного человека.

```json
[
  { "id": "t-12", "subject": "Устаревший фактический адрес", "text": "В заявке старый адрес склада, мы переехали", "status": "OPEN", "reply": null, "applicationId": "a-1031", "updatedAt": "2026-10-20T11:00:00Z" }
]
```

## Открытие результата общего поиска

Подключено к [общему поиску клиента](search.md). Результат открывается по URL, окно закрывается с удалением параметра. Чтение конкретного объекта проверяет доступ на сервере и не зависит от ограничений списка. Ошибка открытия показывается явно.
Вопрос: `/support?faq=ID`, публичный `GET /api/v1/support/faq/{id}`. Обращение: `/support?ticket=ID`, `GET /api/v1/support/tickets/{id}` только для владельца-пользователя; чужое и отсутствующее обращение — одинаковый 404.
